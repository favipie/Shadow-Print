# SQL Server data dictionary

Generated by `document_schema.py` from `001_schema.sql`. This is the active SQL Server implementation; the parent directory's dictionary is preserved MySQL reference material.

All 22 tables are in dbo. Text uses NVARCHAR, timestamps use DATETIME2(3) with UTC by convention, flags use BIT, and event ordering keys use BIGINT IDENTITY. SQL Server does not attach a time zone to DATETIME2. Foreign keys use NO ACTION unless explicitly declared otherwise. Keys, nullability and CHECK conditions below are copied from the authoritative DDL.

Evidence has exactly one source; three filtered unique indexes allow many NULLs while preventing duplicate non-NULL source references. Audit rows have exactly one case/review target. ISJSON validates stored audit snapshots; it does not enforce business semantics.

## provenance

```sql
CREATE TABLE dbo.provenance (
 id NVARCHAR(64) PRIMARY KEY, kind NVARCHAR(64) NOT NULL CHECK (kind IN ('synthetic','public_dataset','manual_review')),
 name NVARCHAR(255) NOT NULL, version NVARCHAR(100) NOT NULL,
 source_url NVARCHAR(1000), license_text NVARCHAR(MAX) NOT NULL, description NVARCHAR(MAX) NOT NULL,
 CHECK (kind <> 'public_dataset' OR source_url IS NOT NULL)
);
```

## evidence

```sql
CREATE TABLE dbo.evidence (
 id NVARCHAR(64) PRIMARY KEY, comment_id NVARCHAR(64), login_id NVARCHAR(64),

 FOREIGN KEY(interaction_id) REFERENCES dbo.interactions(id),

CREATE UNIQUE INDEX ux_evidence_comment_id ON dbo.evidence(comment_id) WHERE comment_id IS NOT NULL;
CREATE UNIQUE INDEX ux_evidence_login_id ON dbo.evidence(login_id) WHERE login_id IS NOT NULL;
```
